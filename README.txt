THE MULTIVERSE OF 3PACK
=======================
  images/  -> ALL pictures AND covers together   (AOT.jpg, AOTcover.jpg ...)
  music/   -> ALL mp3 files                      (AOT.mp3, Zelda.mp3 ...)
  index.html -> the website (open this)

Just dump everything into those 2 folders. No sorting needed.
mp3 names = the picture name + .mp3   (full list in music/PUT-MP3-HERE.txt)

Pictures without an mp3 show with no player.
Pictures without a cover show a plain default vinyl.

CHANGE SONG / ARTIST TEXT: open index.html, find EDIT HERE, add
  song:"My song", artist:"Me"   to that line. (Default text = the title.)

NOTES
  - Names must match exactly, capital letters too (Zelda.jpg, not zelda.jpg).
  - Keep the 2 folders next to index.html.
  - On iPhone, music only starts after you tap the vinyl.
